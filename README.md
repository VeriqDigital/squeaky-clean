# Squeaky Clean Services

A responsive exterior-cleaning demo website for Squeaky Clean Services, also branded as Roberts Revive Services, in Donnellson, Iowa. The site covers residential and commercial exterior cleaning, vehicle detailing, and fleet washing with a clear path to request a free estimate.

## Local development

```bash
npm run dev
```

Quality checks:

```bash
npm run lint
npx tsc --noEmit
npm run build
```
